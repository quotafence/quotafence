# QuotaFence CLI

Install the local-first QuotaFence CLI and terminal dashboard:

```bash
npm install --global @quotafence/cli
qfence status
qfence top
```

The package installs the native binary matching macOS arm64/x64, Windows x64,
or GNU/Linux x64. It does not upload prompts, source code, or credentials.

Documentation and source: <https://github.com/quotafence/quotafence>
